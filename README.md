Designing and implementing a Master's course laboratory focused on advanced control techniques for quadcopters (UAVs).


In order to run this project locally:

1st: Clone this repository

git clone [https://github.com/MathLR7/quadcopter_MPC.git](https://github.com/MathLR7/quadcopter_MPC.git)
cd quadcopter_MPC

2nd: Create a virtual environment (using CMD)
python -m venv venv
.\venv\Scripts\activate.bat

3rd: Install dependencies
pip install -r requirements.txt

4th: Run the project
python main.py
